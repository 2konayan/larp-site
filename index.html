This site focuses on how to install the larp medal on linux

What does larp do?:

Larp awards you with a medal "larp medal" after a larping session(or not)

How do i install larp?

Well copy all this junk


        sudo apt install curl python3
        curl -sSL https://raw.githubusercontent.com/2konayan/larp/main/larp.py -o larp.py
        chmod +x larp.py
        mv larp.py larp
        sudo mv larp /usr/local/bin

CONGRATS!!! now you have larp installed to run it do in the terminal "larp"
